## セクション別 実装設計

### 1. FV（ファーストビュー）

| 項目 | 内容 |
|---|---|
| レイアウト | 2カラム（左：テキスト / 右：イラスト） |
| H1 | 「就活は、出会いだ。」 |
| サブコピー | ペルソナに刺さる一言（"やりたいことがない"層へ） |
| CTA | 「無料ではじめる」ボタン |
| アニメーション | テキストフェードイン |
| イラスト | プレースホルダー（後で差し替え） |

### 2. 体験セクション

| 項目 | 内容 |
|---|---|
| レイアウト | 導入文 + 4枚カード（横並び → モバイルは縦） |
| ビジュアル | 各体験にアイコン（Lucide React）+ イラスト |

| # | タイトル | 説明 |
|---|---|---|
| ① | 何からすればいいか、わかる。 | 自分の経験をAIと一緒に振り返ることで、気づいていなかった強みや価値観が明確になる。「なんとなく」が、言葉になる。 |
| ② | 就活の進め方が、迷わなくなる。 | 自分の強みや価値観が言語化されることで、企業選びや志望動機に一本の軸ができる。軸があるから、次に何をすべきかが自然と見えてくる。 |
| ③ | 選べる会社が、増える。 | 自分のタイプを知ることで、これまで視野に入っていなかった企業や職種が選択肢に入ってくる。思い込みではなく、自分に合った企業と出会える。 |
| ④ | 就活が、怖くなくなる。 | 準備が整っている実感が、不安を前向きな気持ちに変えていく。自分を知っているから、自信を持って選考に臨める。 |

導入文：
> 就活に必要な準備ツールがすべて揃っているから、迷わず集中して取り組める。

### 3. 機能セクション

| 項目 | 内容 |
|---|---|
| レイアウト | カードグリッド（2×2） |
| インタラクション | カードクリック → モーダルで詳細表示 |

| 機能名 | サブタイトル | できること |
|---|---|---|
| 12キャリアタイプ診断 | あなたが気づいていない特性も、言葉にする。 | 12タイプへの分類／強み・弱み・向いている職種の可視化／面接活用アドバイス付きレポートの提供 |
| 自己分析AI | あなたの経験を掘り下げ、就活の軸をつくる。 | 6ステップによる積み上げ設計／STAR法をベースにした経験の深掘り／Will-Can-Mustの整理／志望動機への連携 |
| 企業研究AI | あなたがまだ知らない、相性の良い企業を見つける。 | 企業概要・事業内容・強み・弱みの整理／企業文化・財務情報・最新取り組みの提供／志望動機ワークスペースとの連動 |
| ES添削AI | あなたの魅力を伝えるESを、明確な基準で改善する。 | 4観点（論理性・具体性・適切性・表現力）での評価／結論ファースト構造の確認／数値・事実の有無チェック／設問への適切性の確認／読みやすさ・冗長性の改善 |
| 面接練習AI | Coming Soon… | 2026年夏頃リリース予定。カードに「Coming Soon」バッジを表示。 |

### 6. FAQ

UIはアコーディオン（shadcn/ui `Accordion` コンポーネント）。

| # | 質問 | 回答（要約） |
|---|---|---|
| 1 | 利用料金はかかりますか？ | 完全無料 |
| 2 | スマホでも使えますか？ | 使える。ES添削・面接練習はPCを推奨 |
| 3 | どのくらいの時間がかかりますか？ | 明確なゴールなし。保存機能あり |
| 4 | 他の就活サービスと何が違いますか？ | 準備ツール一括提供。AIが答えではなく自分の言葉に導く設計 |
| 5 | 面接練習AIはいつから使えますか？ | 2026年夏頃リリース予定 |
| 6 | 何年生から使えますか？ | 大学1年生から |
| 7 | 個人情報は安全ですか？ | 情報セキュリティ認証取得済み。プライバシーポリシー参照 |
| 8 | 運営元はどこですか？ | 株式会社ポトス（ODKソリューションズグループ）。NINJAPANと共同提供 |
| 9 | やりたいことがない自分でも使えますか？ | 使える。自分を知ることが就活の第一歩 |

### 7. お問い合わせ

動的フォーム。お問い合わせ種別の選択に応じて入力項目が切り替わる。

**全員共通**
- 氏名
- メールアドレス
- お問い合わせ種別（選択式）
- お問い合わせ内容（自由記述）

**学生選択時のみ追加表示**
- 大学名
- 学年

**種別の選択肢**
- 学生：サービスについて
- 学生：アカウント・登録について
- 学生：技術的な問題について
- 大学関係者・企業：サービス導入について
- 全員：その他

## MicroCMS 管理コンテンツ

| API名 | 理由 |
|---|---|
| `news` | お知らせ・更新情報 |
| `testimonials` | ユーザーの声（増減しやすい） |
| `faq` | FAQ（追加・編集が発生しやすい） |

機能紹介・体験セクションはコピー変更頻度が低いため、コードに直書き。
