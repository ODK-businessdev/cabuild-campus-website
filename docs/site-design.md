### 5-4. 機能セクション（FeaturesSection）

- **見出し**: 「具体的に何ができるか」
- **サブコピー**: 「自己分析から企業研究・ES添削まで、就活準備に必要なツールが一つに。」

- **CTAリンク**: `https://campus.cabuild.jp/`

#### 機能一覧

**① 12キャリアタイプ診断**
- サブタイトル: あなたが気づいていない特性も、言葉にする。
- できること: 12タイプへの分類 / 強み・弱み・向いている職種の可視化 / 面接活用アドバイス付きレポートの提供
- CTA: 「診断してみる」

**② 自己分析AI**
- サブタイトル: あなたの経験を掘り下げ、就活の軸をつくる。
- できること: 6ステップによる積み上げ設計 / STAR法をベースにした経験の深掘り / Will-Can-Mustの整理 / 志望動機への連携
- CTA: 「分析してみる」

**③ 企業研究AI**
- サブタイトル: あなたがまだ知らない、相性の良い企業を見つける。
- できること: 企業概要・事業内容・強み・弱みの整理 / 企業文化・財務情報・最新取り組みの提供 / 志望動機ワークスペースとの連動
- CTA: 「企業を調べてみる」

**④ ES添削AI**
- サブタイトル: あなたの魅力を伝えるESを、明確な基準で改善する。
- できること: 4観点（論理性・具体性・適切性・表現力）での評価 / 結論ファースト構造の確認 / 数値・事実の有無チェック / 設問への適切性の確認 / 読みやすさ・冗長性の改善
- CTA: 「ESを添削してみる」

**⑤ 面接練習AI**（Coming Soon）
- 詳細: 2026年夏頃リリース予定
- CTAなし・Coming Soonバッジ表示

### 5-5. 使い方・流れ（HowToSection）

- **見出し**: 「使い方・流れ」
- **サブコピー**: 「あなたの学年を選んでください」
- **背景**: `#299dd9`（ブルー）・白文字
- **UI**: 学年別タブ（大学1〜4年生）・`Client Component`

#### タブ構造
- タブ4枚: ピル型ボタン（`rounded-full`）
  - アクティブ: 白背景・ブルー文字・`font-weight: 600`
  - 非アクティブ: 透明背景・白文字・`font-weight: 500`

#### パネル構造（各学年共通）

```
[ YEAR X ラベル（左寄せ） ]      [ 補足メモ（右カラム・pt-8） ]
[ タイトル（text-2xl・白） ]
[ サブタイトル（text-sm・白） ]

[ FIRST STEP カード ]  [ SECOND STEP / 活用シーン カード ]
```

- ヒーロー + 補足メモ: 左右2カラム（PC）/ 縦並び（SP）・`items-start`・右カラムは`md:pt-8`
- カード: 白背景・`rounded-xl`・左右2カラム（PC）/ 縦並び（SP）
- 補足メモ: 「。」区切りで改行表示・`text-sm text-white font-medium`

#### 学年別コンテンツ

**大学1年生 — YEAR 1**
- タイトル: まず「自分」を知るところから
- サブタイトル: バイト・ゼミ・サークル選びを就活目線で考え始める
- 左カード（FIRST STEP）: 自己理解を深める（①診断 ②自己分析 ③企業研究）
- 右カード（活用シーン）: バイト・ゼミ決め前の自己理解入口として など
- 補足: 今は焦らなくてOK。診断・自己分析だけ先にやっておくと…

**大学2年生 — YEAR 2**
- タイトル: 長期インターンへの準備を本格化
- サブタイトル: エントリーシートの基礎を作り、実務経験を積み始める
- 左カード（FIRST STEP）: 土台をつくる（①診断 ②自己分析 ③企業研究）
- 右カード（SECOND STEP）: 選考対策へ（④ES添削 ⑤面接練習）
- 補足: 長期インターンのエントリー時期に合わせてES作成と面接練習を集中的に…

**大学3年生 — YEAR 3**
- タイトル: サマーインターン・早期選考を狙う
- サブタイトル: 夏までに全ステップを完走し、秋の早期内定を獲りにいく
- 左カード（FIRST STEP・春）: 5月までに完了させる（①診断 ②自己分析 ③企業研究）
- 右カード（SECOND STEP・夏〜秋）: 選考を突破する（④ES添削 ⑤面接練習）
- 補足: サマーインターン（6月締切目安）のESと面接練習が最優先…

**大学4年生 — YEAR 4**
- タイトル: 今すぐ動く、全力で追い上げる
- サブタイトル: 本選考ESと面接対策に集中して内定を獲りにいく
- 左カード（FIRST STEP・即着手）: 今週中に終わらせる（①診断 ②自己分析 ③企業研究）
- 右カード（SECOND STEP・並行）: 選考を同時進行（④ES添削 ⑤面接練習）
